Portal de Eventos Universitários Esse é um projeto de um site completo para divulgar e gerenciar eventos de uma universidade. Criei essa aplicação para colocar em prática conceitos fundamentais de desenvolvimento web, mantendo o código limpo, semântico e fácil de navegar tanto pelo computador quanto pelo celular. O que o projeto faz O site é dividido em três páginas integradas: Página Inicial (index.html): Mostra uma apresentação da instituição e uma grade com 6 cards de eventos (palestras, minicursos, workshops) usando Flexbox. Programação (programacao.html): Uma tabela organizada com as datas, horários e locais de cada atividade, utilizando mesclagem de células (rowspan e colspan) para avisos e eventos do mesmo dia. Inscrição (inscricao.html): Um formulário de cadastro para alunos, com campos obrigatórios de e-mail, curso, seleção de evento e escolha de modalidade (presencial ou online). Tecnologias que utilizei  HTML5: Estruturação semântica do conteúdo (header, main, article, table, form>...). CSS: Estilização visual, cores, efeitos nos cards e layout responsivo.  Como abrir o projeto na sua máquina 1. Baixe os arquivos do repositório para o seu computador. 2. Certifique-se de que todos os arquivos (`index.html`, `programacao.html`, `inscricao.html`, `style.css` e `README.md`) estão na mesma pasta. 3. Clique duas vezes no arquivo `index.html` para abrir o site direto no seu navegador de preferência.
